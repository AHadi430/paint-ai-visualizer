Can't reach Griplac

The app runs on your Mac, and the Mac isn't answering right now.

  1. Make sure the Mac is on, awake and online.
  2. In the app folder, run npm run tunnel and keep that window open. If it shows a new address, run the app from Xcode again.
  3. In the app folder, run npm run phone, and keep this phone on the same Wi-Fi as the Mac.
  4. Check the address below matches the Network address npm run phone shows. If it doesn't, the Mac got a new one: run npm run ios and press Run in Xcode again.
